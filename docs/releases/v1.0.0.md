# Tally v1.0.0 (NEAR HACKATHON, 14 Nov 2026)

Draft release notes. Not published as a GitHub release.

**Tally lets an AI agent pay only for items a merchant signed, at the signed price, inside the owner's rules,
enforced by a NEAR contract and a pay-only NEAR key.**

## Highlights

- Tally contract on testnet (`tallynear.testnet`), code hash `EVP9Y5zkGVSV5juPCvwgqbM2XEdoZBY2LFDPUVba8k5e`,
  a reproducible build of commit `2381dae` with NEP-330 metadata.
- Phone app on Cloudflare Workers: passkey → NEAR implicit account, scan-to-pay, Second Look with Face ID,
  red team, receipts, family top-ups.
- NEAR integrations with live evidence ([docs/proofs.md](../proofs.md)): NEP-366 gasless agent, Sputnik DAO
  arbiter, verified NEAR AI Cloud TDX attestation, Agent Market listing, Chain Signatures receipts, NEAR Intents
  deposits, HOT wallet sign-in.
- SDK, agent CLI, MCP server (6 tools), Agent Market worker.
